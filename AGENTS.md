## Project
Offline-first iOS/iPadOS SwiftUI + SwiftData MVP for private music teachers.

## Core principles
- Keep MVP simple, buildable, testable.
- SwiftUI + SwiftData. No cloud sync, login, push, online payment, student/parent portal.
- Money stored as Int (TWD whole units; for other currencies treat as cents).
- UUID-based references between models for MVP simplicity.
- AI layer is behind `AIProvider` protocol; only `MockAIProvider` is shipped — no network calls, no API key.
- AI produces editable drafts only; never auto-send, never judge talent, never label students. Prompts in `AIPromptTemplates.safetyClauses` are tested.
- Practice recordings must be copied into the app sandbox before storing paths.
- Progress PDFs focus on learning history; payment info is NOT included by default.

## Architecture
- `MusicTeacherStudio/App` — entry + RootView (TabView)
- `MusicTeacherStudio/Models` — SwiftData @Model types
- `MusicTeacherStudio/Services` — pure-Swift services (no ModelContext inside)
- `MusicTeacherStudio/Views` — SwiftUI screens
- `MusicTeacherStudio/Utilities` — MoneyFormatter, DateFormatterUtility, FileStorageUtility, PreviewData
- `MusicTeacherStudioTests` — XCTest

## Testing
- `xcodebuild -scheme MusicTeacherStudio -destination 'platform=iOS Simulator,name=iPhone 17 Pro' test`
- Coverage: PaymentBalanceService, LessonScheduler, AttendanceService, AssignmentService, StudentProgressReportRenderer.

## Regeneration

```

```

## UI priorities
1. Fast attendance + lesson notes (30s flow).
2. Visible outstanding balances.
3. (deferred) One-tap parent message draft.
4. Easy student lookup.
5. Offline reliability.
